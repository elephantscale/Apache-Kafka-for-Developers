# Apache Kafka for Developers

Elephant Scale

---

## Agenda

**Introduction (1 day)** — fundamentals + first hands-on

- **1.** What Is Kafka and Why
- **2.** Core Concepts
- **3.** Kafka 4 Architecture
- **4.** Hands-On Fundamentals

**Intermediate (3 days)** — building production streaming applications

- **5.** Producer Internals
- **6.** Consumer Internals
- **7.** Delivery Semantics & Transactions
- **8.** Serialization & the Schema Registry
- **9.** Kafka Connect
- **10.** Stream Processing (Kafka Streams & Flink SQL)
- **11.** Reliability, Scaling & Operations for Developers

Notes: Four days end to end, deliverable as one track or as two standalone courses. The intro day makes it accessible to newcomers; the intermediate days give working developers real depth.

---

## Pre-requisites and Expectations

 * Practical programming experience

     - Java examples throughout — the Kafka Java client, built with Maven

 * Comfort with the **Linux command line** and a text editor

 * **Docker** on your machine — that's the whole lab environment (no Kubernetes, no cluster admin)

 * Basic familiarity with messaging or data-processing concepts is helpful, not required

 * Curiosity!

   - Ask a lot of questions

Notes: This is a developer course — the emphasis is on writing code against Kafka, not administering a cluster. For the intermediate days we assume Kafka fundamentals (the intro day, or equivalent experience).

## What You'll Be Able to Do

By the end of the track you will be able to:

 * Explain Kafka's architecture and core abstractions — and how **KRaft** replaces ZooKeeper

 * Write **producers and consumers**, and reason about partitioning, ordering, and parallelism

 * Choose and configure **delivery guarantees** — at-least-once, at-most-once, exactly-once

 * Manage schemas and evolution with the **Schema Registry** (Avro, Protobuf, JSON Schema)

 * Build data pipelines with **Kafka Connect**, and process streams with **Kafka Streams & Flink SQL**

 * Apply reliability basics: replication, ISR, consumer lag, and tuning
